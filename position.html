CSS position

This page shows main position values in CSS.

Static

Static is the default. Elements stay in the normal page flow.

Static

Relative

Relative keeps the element in the normal flow, but lets us move it with top, bottom, left and right.

Relative

Absolute

Absolute moves an element relative to its nearest relative positioned parent.

Absolute

Fixed

Fixed stays in the same place even when the pages scrolls.

Fixed
Look at the bottom right of the screen.

Sticky

Sticky acts like relative until it reaches a certain scroll position, then changes to act like fixed.

Sticky

Scroll inside the page to see sticky in action.
