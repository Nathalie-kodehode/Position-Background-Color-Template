CSS Background Properties

This page shows common background properties in CSS.

Background Colour

This changes the background colour of an element.

background-color: coral

Background Image

This adds an image as the background of the element.

background-image

Background Repeat

This controls whether the background image repeats or not.

background repeat

Background Size

This controls the size of the background image.

background size

Background Position

This controls where the background image sits.

background position

Background Attachment

Background attachment lets us attach a backgronud image to stay fixed while the page scrolls. (parallax effect)

background attachment

Background Shorthand

The shorthand lets us write several background properties in one line.

backgroud shorthand
